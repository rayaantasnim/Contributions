Authored Problem #049 (Combinatorics) OLYMPIAD FINAL LEVEL

PROBLEM STATEMENT:

Let $S = \{1, 2, \dots, 2n\}$. A subset $A \subseteq S$ is termed balanced if no two elements in $A$ sum to $2n + 1$. Determine the exact number of balanced subsets of $S$ containing exactly $n$ elements.

PROOF OVERVIEW:

Partition $S$ into $n$ disjoint pairs $P_i = \{i, 2n + 1 - i\}$ for $i = 1, 2, \dots, n$. For a subset $A$ of size $n$ to be balanced, $A$ cannot contain both elements of any pair $P_i$.

Since $|A| = n$, $A$ must choose exactly one element from each of the $n$ disjoint pairs $P_i$. Thus, each pair provides 2 independent choices.

FINAL RESULT: Total balanced subsets = $2^n$. $\blacksquare$
